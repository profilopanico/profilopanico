PROFILOPANICO.EXE ================== Welcome. You are inside a computer that was left on, on purpose. This is not a metaphor for a portfolio — it IS a portfolio, disguised as a desktop, disguised as an operating system that stopped receiving updates sometime around 1998. Everything you can open here is a small piece I made. Some are finished. Some are placeholders, waiting for the real file to be dropped in later. Click around. Drag the windows. Minimize things. Nothing here is precious — it's a machine, and machines are meant to be used. ------------------------------------------------------------ ABOUT THIS PROJECT "profilopanico" was built for Net Art 1, taught by Domenico Quaranta, at Accademia di Belle Arti di Brera. The starting question was simple: what if the interface itself was the artwork, instead of just the container for it? A desktop is already a kind of self-portrait — the icons you keep, the ones you hide, the folder you never open again, the assistant pretending to be smart, the "access denied" you put on your own life. Somewhere between every icon and every window there is a person doing invisible work to keep the illusion running — answering as the "AI", drawing the icons, writing this text, watching you read it right now. That labor is usually hidden by design. Here it's just... left half-visible. Like Eva and Franco Mattes' work keeps reminding us: there is always a human behind the machine, even when the machine insists otherwise. ------------------------------------------------------------ HOW TO USE THIS COMPUTER - Double-click an icon to open it. - Drag any window by its title bar. - Use the _ / □ / X buttons to minimize, maximize, or close a window. - Click START for the full list of what's on this machine. - Keep an eye on the system tray. It's always watching. - Don't trust everything you read on this desktop. ------------------------------------------------------------ Thanks for stopping by. — the person currently operating this machine
